HOW TO JOIN
01

Copy the server IP

Click the IP box above — play.avento.net copies to your clipboard.

02

Go to Multiplayer → Add Server, and paste the IP in.

03

Read the rules

Check the #rules channel on Discord before you start building.

Keep it fair
SERVER RULES
  • No griefing or stealing outside claimed land.
  • No hacked clients, X-ray, or cheats of any kind.
  • Respect every player — no hate speech or harassment.
  • No spamming or advertising other servers.
  • PvP only in designated zones unless agreed.
  • Report bugs and exploits, don't abuse them.
